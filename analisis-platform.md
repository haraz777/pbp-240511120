**ANALISIS KOMPARATIF PLATFORM**

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript, PHP, Java, dll | Python, Java, C++, C#, dll | C, C++, Kotlin, Java, XML, dll |
| **Arsitektur** | N-layer, Clean architectures, MVC, client-server, SPA, dll | Client Server, MVC, Arsitektur bertingkat dll | Arsitektur UDF, Coroutine dan flow, arsitektur adaptif dan berlapis, dll |
| **Cara distribusi** | Diakses melalui browser dengan URL | Didistribusikan melalui installer atau toko aplikasi desktop | Didistribusikan melalui PlayStore maupun AppStore |
| **Keunggulan** | Tidak perlu di download, pembaruan dari server, mudah diakses di perangkat manapun | Kinerja stabil, memanfaatkan sumber daya komputer maksimal, bisa offline | UI/UX menarik, bisa offline, mudah diakses dengan Smartphone |
| **Keterbatasan** | Harus selalu terhubung internet, akses hardware terbatas | Butuh lisensi asli, harus diinstal, butuh spesifikasi hardware tertentu | Ukuran layar kecil, terbatas tergantung spesifikasi RAM Smartphone |
| **Contoh aplikasi** | Canva web, Google Docs, Great System UMC, dll | Microsoft Office, VS Code, Mozilla Firefox, Adobe Photoshop, dll | Youtube, Gmail, Shopee, WhatsApp, Instagram, dll |

**REFLEKSI**

Platform yang menarik untuk dipelajari adalah platform web karena orang-orang akan mudah menemukan web saya tanpa harus memerlukan instalasi yang mudah diakses melalui browser apapun.

Tantangan terbesar saat setup environment-nya yaitu saat menginstal aplikasi atau hal-hal yang dibutuhkan terkait membuat platform website karena itu membutuhkan pemahaman dan aplikasi terkait harus bisa dijalankan secara efektif dan benar. Jika saja saya salah mensetup, aplikasi tersebut tidak akan berjalan dengan lancar dan benar seperti apa yang kita butuhkan. Bahkan ada beberapa aplikasi yang kita download harus bisa kita pakai atau run juga di CMD maupun terminal komputer kita. Proses konfigurasi path dan environment variables sering kali menjadi kendala teknis yang cukup membingungkan bagi pemula seperti saya.
